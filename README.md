# Посмотри в окно

**Ссылка на репозиторий:** [https://github.com/IDLMan/posmotri-v-okno-ad](https://github.com/IDLMan/posmotri-v-okno-ad)

Одностраничное веб-приложение для поиска и просмотра видео с видами из окон в разных городах. Можно искать видео по названию города и времени суток, переключаться между роликами и загружать дополнительные карточки.

Проектная работа второго спринта курса Яндекс Практикума «Фронтенд-разработка». В рамках проекта выполнена стилизация готового приложения по макету с использованием CSS.

## Запуск

Откройте `index.html` в браузере. Для загрузки видео необходимо подключение к интернету.
